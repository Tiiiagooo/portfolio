# Portfolio de Tiago de Carvalho Bene

Site d'une page : informaticien et linguiste (NLP, LLM, data engineering).

- Une intro courte : un ordinateur s'allume, puis on zoome dans l'écran.
- Mon parcours, raconté au défilement.
- À venir : mes projets (données, méthode, tâche), une démo de mon agent IA, une analyse du marché de l'emploi data et IA.

## Ouvrir le site

Double-cliquer sur `index.html` : pas de serveur ni de compilation (HTML, CSS et JavaScript sans framework).

| Fichier | Rôle |
|---|---|
| `index.html` | contenu et structure de la page |
| `css/style.css` | couleurs, typographie, mise en page, intro |
| `js/intro.js` | intro de l'ordinateur (durée réglable avec `LENTEUR`) |
| `js/theme.js` | sélecteur des trois styles (sombre, clair, éditorial) |
| `js/parcours.js` | animation du parcours et des sections au défilement |
| `assets/` | CV en PDF (sans numéro de téléphone) |

Accessibilité : l'intro se passe avec Échap ou le bouton « Passer l'intro » ; avec « réduire les animations », elle est jouée en fondus, sans zoom.
